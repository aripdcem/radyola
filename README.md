# Radyola / Radyola

Çoklu platform internet radyo çalar uygulaması.

## Platformlar

### 🍎 macOS — Radyola

SwiftUI + AVFoundation tabanlı menü çubuğu radyo çalar.

- **Konum:** [`macosx/`](macosx/)
- **Gereksinim:** macOS 13.0+ (Ventura), Xcode
- **Teknoloji:** Swift, SwiftUI, MenuBarExtra, AVPlayer

### 🐧 Linux — Radyola

GTK4 + Libadwaita + GStreamer tabanlı native radyo çalar.

- **Konum:** [`linux/`](linux/)
- **Gereksinim:** Debian 13+ (Trixie), Python 3.11+, GTK4, GStreamer
- **Teknoloji:** Python, GTK4, Libadwaita, GStreamer
- **Çalıştırma:** `python3 linux/radyola.py`
